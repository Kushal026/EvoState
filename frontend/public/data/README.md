## 📌 Overview
This directory contains fully reproducible, empirically verified benchmark datasets and publication-quality figures generated by the DataForge experiment pipeline.

> **CRITICAL CLASSIFICATION:**
> All files in this directory are **PRECOMPUTED BENCHMARKS** generated from real model evaluations ($N=30$ Monte Carlo seeds per parameter point). They are formatted for direct ingestion by frontend dashboards, comparison charts, and scientific evaluation sheets.

---

## 📂 Directory Contents

### 1. Tabular Master Datasets
- **`sweeps_master.csv` (643 KB):** Full trial-level dataset containing 2,700 individual evaluation records with configuration, seed, model, accuracy, error rate, latency (ms), and inference steps.
- **`summary_statistics.csv` (16 KB):** Aggregated metrics across models and parameter sweeps, including sample size ($N$), mean accuracy, standard deviation, 95% confidence intervals, error rate, mean latency, median latency, 95th percentile latency, and mean inference steps.

### 2. Machine-Readable JSON Feeds (Frontend Ready)
- **`sweeps_data.json` (1.5 MB):** Complete master JSON archive of all trial records with embedded configurations.
- **`summary_stats.json` (59 KB):** Aggregate statistics dictionary for charting components.
- **`sequence_length_sweep.json` (322 KB):** Sequence horizon scaling data ($T \in [16, 1024]$).
- **`memory_capacity_sweep.json` (361 KB):** Associative capacity stress data ($N_{\text{pairs}} \in [1, 32]$).
- **`interference_sweep.json` (331 KB):** Conflicting key overwrite data ($N_{\text{overwrites}} \in [1, 10]$).
- **`inference_effort_sweep.json` (388 KB):** Test-time compute scaling data ($C_{\text{infer}} \in [1, 16]$).

### 3. Publication-Quality Plots (`data/precomputed/plots/`)
All figures are rendered at **300 DPI** using scientific styling, color-coded model palettes, and 95% bootstrap confidence bands:
1. **`plot1_accuracy_vs_sequence_length.png`:** Accuracy vs. Sequence Length ($T \in [16, 1024]$ tokens on logarithmic scale).
2. **`plot2_accuracy_vs_memory_capacity.png`:** Accuracy vs. Stored Key-Value Pairs ($N_{\text{pairs}} \in [1, 32]$).
3. **`plot3_error_rate_vs_interference.png`:** Error Rate ($1 - \text{Accuracy}$) vs. Overwrite Count ($N_{\text{overwrites}} \in [1, 10]$).
4. **`plot4_accuracy_vs_inference_effort.png`:** Accuracy vs. Inference Effort ($C_{\text{infer}} \in [1, 16]$ steps).
5. **`plot5_latency_vs_inference_effort.png`:** Query Latency Overhead vs. Inference Effort.
6. **`plot6_accuracy_latency_tradeoff.png`:** Accuracy vs. Latency Pareto Frontier across all parameter regimes.
7. **`plot_all_panels.png`:** Composite 2×3 multi-panel figure displaying all 6 evaluation dimensions.

To regenerate all CSVs, JSONs, and 300 DPI figures from scratch using identical deterministic seeds:

```powershell
python scripts/reproduce_all.py --trials 30 --seed 42 --output data/precomputed
```

Execution takes approximately 60–80 seconds on standard CPU hardware.
